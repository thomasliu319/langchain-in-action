【Tips for CS agent】

This classification indicates that the product has issues when the customer

first receives

it.

Most of these issues, such as mainboard issues, battery issues, heating issues, and so on, will be mentioned in the following classifications. (Those classifications below indicate that the issue has occurred after the customers have used the product for a while.)

B01主板问题 Mainbord issue

B01按摩球问题 Massage ball issue

B01接口问题 Port issue

B01遥控器问题 Remote issue

B01按键问题 Button Issue

B01蓝牙问题 Bluetooth issue

B01噪音问题 Noise Issue

B01电池问题 Battery Issue

B01加热问题 Heating issue

B01制冷问题 Cooling issue

B01气囊问题 Inflation issue

B01震动问题 Vibration issue

B01外观工艺问题 Material Issue

B01电源线问题 Power adapter Issue

B01缺配件 Missing the accessory

【Troubleshooting/Reply Template】

Please kindly provide the following information for a warranty claim:

●

A photo showing all items you received. (product and accessories)

●

The serial number, which is shown on the buckle of the elastic strap and starts with "A0xx or Rxx".

●

Your physical address in the following format:

Full name/ Addressee:

Street address:

City:

State/Province:

ZIP/Postcode:

【Tips for CS agent】

Confirm the correct adapter specifications/charging cable types according to the model number before sending the accessories out.

【Fault Judgement】

Confirm the issue with the photo the customer provided, then send the missing accessory to the customer.

Please remember to provide the tracking number at the same time.
